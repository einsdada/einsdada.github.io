# Markdown 快速参考

这是一篇 Markdown 语法速览，用来展示博客的排版能力。写文章时，你只需要会下面这些就够了。

## 标题与强调

在行首加 `#` 的数量表示标题层级，`##` 是二级标题，`###` 是三级标题。

**加粗**、*斜体*、`行内代码`，这些标记都会在正文里生效。

## 列表

无序列表和有序列表都很常用：

1. 先列出思路
2. 再展开细节
3. 最后总结

- 要点一
- 要点二
- 要点三

## 引用与分隔线

> 引用块适合放一段摘录或提示。

---

## 表格

| 语法 | 效果 |
| --- | --- |
| `**文字**` | 加粗 |
| `*文字*` | 斜体 |
| `` `代码` `` | 行内代码 |

## 代码块

```python
def greet(name):
    """示例：带语法高亮的代码块"""
    return f"你好，{name}！"

print(greet("einsdada"))
```

> 注：本文为示例文章，用于展示 Markdown 的排版效果，内容可随时替换。
